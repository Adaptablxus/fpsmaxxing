# FPSMaxx 1.0.0 archive

This branch preserves the FPSMaxx 1.0.0 jar for Minecraft 26.2.

- FPSMaxx-1.0.0-mc26.2.jar is the recovered build that was originally published as 1.1.0. It has been renumbered to 1.0.0 because no earlier 1.0.0 source snapshot exists.
- The original 1.0.0 source was not preserved; this branch contains the jar and archive notes only.
- Current releases and source live on main.

FPSMaxx is a client-side Fabric optimization mod. See https://github.com/Adaptablxus/fpsmaxxing for current documentation.
